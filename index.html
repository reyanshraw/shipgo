FAQ

Common questions.

Does shipgo replace Git?
No — it wraps Git. Every shipgo command maps directly to a Git, GitHub CLI, or GitLab CLI invocation. You can always inspect what it runs, and it works alongside your existing setup.
How does shipgo handle protected branches?
Branches listed in PROTECTED_BRANCHES (default: main, master, develop) warn before any force push. All force pushes use --force-with-lease — never the raw --force.
Which operating systems are supported?
macOS, Linux, and Windows (via Git Bash or WSL). The script is pure Bash with zero external dependencies beyond git itself. Optional integrations (gh, glab) activate only when detected.
Can I configure defaults?
Yes. Shipgo reads from ~/.shipgorc. Override DEFAULT_REMOTE, PROTECTED_BRANCHES, and CONFIRM_FORCE there. Use shipgo config to edit, or shipgo init-config to generate the file.
Is it safe in CI environments?
Absolutely. Set SHIPGO_YES=1 to skip all interactive confirmations. Combined with its deterministic behavior and shellcheck-clean code, it's safe to use in automation.
