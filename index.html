❯ shipgo
Features Install GitHub

Git push, perfected.

The ultimate CLI wrapper for pushing code, managing PRs, syncing repositories, and handling tags. Zero friction, interactive interface.

Get Started View on GitHub
~/project ❯ shipgo push
[*] Pushing main -> origin/main (3 commits)
[OK] Push complete.

~/project ❯ shipgo pr
[*] Creating pull request...
[OK] Opened in browser.
⚡

Smart Upstream

Automatically detects missing upstreams and sets them on the fly. No more git push --set-upstream.

🛡️

Safe Force Push

Built-in protection for protected branches. Always defaults to --force-with-lease to prevent overwriting teammates' work.

🚀

PR & MR Generation

Seamlessly integrates with GitHub CLI and GitLab CLI to create pull requests or merge requests directly from the terminal.

🎨

Interactive Menu

Just run shipgo with no arguments to get a beautiful, color-coded interactive menu for all commands.

🔄

One-Click Sync

Fetch, pull with rebase, and push your changes in a single command with shipgo sync.

🏷️

Release Management

Create annotated tags, push them, and even delete remote tags with ease using the tag and release commands.
