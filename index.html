Built for modern workflows.

Stop memorizing 50 git aliases. `shipgo` gives you safe, standard commands that work identically across every OS and CI pipeline.

Safe by Default

Never accidentally overwrite remote history. `shipgo` enforces --force-with-lease under the hood.

Cross-Platform

Native support for Bash, Windows CMD, and PowerShell. Write your CI scripts once, run them anywhere.

PR Automation

Push your branch and open a GitHub PR or GitLab MR instantly. Draft PRs are just one flag away.

Agent-Ready

Ships with AGENTS.md, repo policies, and AI workflow guards out of the box. Perfect for Claude Code or Cursor.

One-Shot Sync

Fetch, rebase with autostash, and push your changes in a single, bulletproof command.

Release Engine

Create annotated SemVer tags and push them instantly. Perfect for automated release pipelines.

Every command you need.

Type shipgo in your terminal to launch the interactive menu.

shipgo push Push current
shipgo up Set upstream
shipgo all Push all branches
shipgo tags Push tags
shipgo force Safe force push
shipgo del <br> Delete remote branch
shipgo sync Fetch + Pull + Push
shipgo pull Rebase + Autostash
shipgo amend Amend + Force push
shipgo cleanup Delete merged local
shipgo pr "Title" GitHub PR
shipgo draft-pr Draft PR
shipgo mr "Title" GitLab MR
shipgo status Branch + Diff
shipgo doctor Env health check
shipgo whoami Git identity
shipgo ping Test connection
