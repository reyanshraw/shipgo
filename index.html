Features GitHub

Git push, perfected.

A CLI that handles upstreams, PRs, and safe force pushes so you can ship code without friction.

$ curl -fsSL https://raw.githubusercontent.com/reyanshraw/shipgo/main/install.sh | bash

Smart Upstream

Auto-detects missing upstreams and sets them on the fly. No more --set-upstream.

Safe Force Push

Protected branches are respected. Uses --force-with-lease by default.

PR & MR Generation

Creates pull requests or merge requests directly from the terminal via gh or glab.

Interactive Menu

Run shipgo with no arguments for a beautiful, color-coded command menu.

One-Click Sync

Fetch, pull with rebase, and push in a single command with shipgo sync.

Release Management

Create annotated tags, push them, and delete remote tags with tag and release.
